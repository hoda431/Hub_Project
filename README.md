# Expense Tracker

## What the project does
Expense Tracker is a Python application that helps users manage their expenses.
Users can add expenses, view all expenses, calculate total expenses, and search expenses by category.

## How to run it
1. Make sure Python is installed.
2. Open the project folder.
3. Run the application using:

python expense_tracker.py

## Main Features
- Add new expenses (amount, category, and description).
- View all expenses.
- Calculate total expenses.
- Save expenses in a JSON file.
- Load saved data automatically.
- Search expenses by category.
